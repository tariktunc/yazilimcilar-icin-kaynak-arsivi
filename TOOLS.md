# Araçlar (Tools)

Günlük yazılım işini hızlandıran ücretsiz/freemium araçlar.

## Editör / IDE

- [VS Code](https://code.visualstudio.com/) — ücretsiz, geniş eklenti ekosistemi
- [Cursor](https://cursor.com/) — AI destekli editör
- [Neovim](https://neovim.io/) — terminal tabanlı, hızlı

## AI Kod Asistanları

- [Claude Code](https://claude.com/claude-code) — terminal tabanlı ajan
- [GitHub Copilot](https://github.com/features/copilot)
- [v0.dev](https://v0.dev/) — UI üretimi

## API / Test

- [Postman](https://www.postman.com/)
- [Insomnia](https://insomnia.rest/)
- [httpie](https://httpie.io/)

## Tasarım

- [Figma](https://figma.com/) — arayüz tasarımı
- [Excalidraw](https://excalidraw.com/) — hızlı diyagram/wireframe

## Verimlilik / CLI

- [tldr pages](https://tldr.sh/) — kısa komut özetleri
- [jq](https://jqlang.org/) — JSON işleme
- [fzf](https://github.com/junegunn/fzf) — fuzzy arama

## Deploy / Hosting
